How curation works

  1. Look. Every annotated box in this image's label file is drawn and numbered (#0, #1, …). Both classes are shown: red = periapical_lesion, orange = caries.
  2. Decide per box. Click the box on the image — or its row in the right panel — to cycle:
    • keep correct disease, correct class, correct location
    • drop wrong box: around crown/cervical region, burnout, interproximal shadow, pulp chamber, artifact, normal anatomy
    • relabel real disease but wrong class — shown dashed in the other class's color
  3. Save & Next (button, or →/Space). Decisions save automatically when you move on. Progress resumes where you left off, any time.
  4. If all boxes get dropped, the image becomes a clean negative example — that's valuable too.

Boxes are not draggable in this tool — clicking only changes the decision. Keyboard shortcuts: ← prev, →/Space next, 1…9 cycle box #. On mobile: tap boxes and use the buttons.
